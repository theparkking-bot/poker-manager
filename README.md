# Poker Manager 1.0 by theparkking

Рабочий прототип мобильного веб-приложения для управления живыми покерными турнирами. Интерфейс Emerald Gold. Данные хранятся локально в браузере.

## Публикация на GitHub Pages
1. Создайте **новый отдельный** публичный репозиторий, например `poker-manager`.
2. Загрузите `index.html`, `sw.js`, `manifest.webmanifest` в корень репозитория.
3. В **Settings → Pages → Build and deployment** выберите **Deploy from a branch**, ветку `main`, папку `/ (root)`.
4. После публикации откройте адрес вида `https://ВАШ-ЛОГИН.github.io/poker-manager/` на телефоне.

## Ограничения текущей сборки
- ICM-калькулятор пока не реализован, есть только вход в раздел и ручная настройка призовых.
- Голосовые объявления, полноценные звуки, статистика по всем турнирам, продвинутые перерывы и шаблоны требуют следующей итерации.
- При блокировке телефона браузер может приостанавливать JavaScript. Восстановление часов происходит по времени устройства, но фоновый звук не гарантирован.
- Данные не синхронизируются между устройствами. Используйте экспорт резервной копии.
- Приложение не предназначено для денежных расчётов без проверки и тестирования.
